FILTER CORRECTIONS
- Countries are stored as separate values, so a record covering Germany and
  India appears under both "Germany" and "India" rather than a combined filter.
- Aliases are consolidated: UK/United Kingdom, US/USA/United States,
  UAE/United Arab Emirates, and Netherlands/The Netherlands.
- Study levels are separate and consistently named. A scholarship covering
  Bachelor's, Master's and PhD study appears under each individual filter.
- Correct study-level labels:
  School, Certificate / Short Course, Bachelor's, Master's, Postgraduate Diploma, PhD, Postdoctoral, Research Fellowship, Exchange Programme, Online Course, Not specified

UPLOAD TO GITHUB
1. Open https://github.com/supermillie77/ghazza-scholarships
2. Choose Add file > Upload files.
3. Upload index.html, data.json and README.txt from this folder.
4. Commit the changes.
5. If GitHub Pages is enabled, allow a few minutes for the site to refresh.

The app works from index.html alone because the complete database is embedded.
data.json is also supplied for future updates and database reuse.

Important: scholarship deadlines, eligibility, funding, visas, travel and safe
passage can change. Applicants must confirm details with the official provider.

GHAZZA SCHOLARSHIPS — WORLDWIDE GITHUB VERSION
=================================================

CONTENTS
--------
index.html  Complete bilingual website, styling and app logic.
data.json   Worldwide scholarship database (148 opportunities).
readme.txt  These instructions.

WHAT WAS FIXED
--------------
- All 148 worldwide opportunities from the supplied original app are preserved.
- Country and region names are normalised so equivalent labels appear once.
- Combined country fields can be found under each relevant country.
- Study levels are split into clear, unique choices and sorted logically.
- Search, country, study-level and spreadsheet-section filters remain available.

UPLOAD TO GITHUB
----------------
1. Open https://github.com/supermillie77/ghazza-scholarships
2. Select "Add file", then "Upload files".
3. Upload index.html, data.json and readme.txt together to the repository's main folder.
4. Enter a commit message such as "Update worldwide scholarship directory".
5. Select "Commit changes".

PUBLISH WITH GITHUB PAGES
-------------------------
1. In the repository, open Settings.
2. Select Pages.
3. Under "Build and deployment", choose "Deploy from a branch".
4. Choose the main branch and the / (root) folder.
5. Select Save.

GitHub will then show the public website address. The site can be opened by anyone;
visitors do not need a GitHub or ChatGPT account.

IMPORTANT
---------
Scholarship information, deadlines, eligibility, funding, travel and evacuation
arrangements can change. A listing does not guarantee admission, funding, a visa,
evacuation support or safe passage. Applicants should verify details with the
institution using the official page.
